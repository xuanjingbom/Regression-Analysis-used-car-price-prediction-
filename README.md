# Used Car Price Prediction

## Overview

This project develops a simple linear regression model to predict used car prices based on mileage driven.

The objective is to understand the relationship between vehicle mileage and market value while applying regression analysis techniques.

## Tools Used

* R
* Linear Regression
* Statistical Analysis
* Data Visualization
